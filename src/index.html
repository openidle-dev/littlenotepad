    Multiple Cursors

    Place more than one cursor in the document at the same time. Every keystroke, deletion, or paste applies to all cursor positions simultaneously — great for renaming a variable, editing multiple lines at once, or making column edits.

    HOW TO USE
    • Alt + Click — add an extra cursor at the clicked position
    • Ctrl + D — select the next occurrence of the current word (adds a cursor there); repeat to keep selecting more
    • Ctrl + Alt + Up / Down — add a cursor on the line above or below
    • Escape — collapse back to a single cursor
    EXAMPLE
    • Double-click a variable name to select it, then press Ctrl + D repeatedly to select every occurrence, and type the new name — all replaced at once.
    • Hold Alt and click at the start of several lines to build a column cursor, then type or paste to prefix every line simultaneously.
